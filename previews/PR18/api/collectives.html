source
julia
UCC.Broadcast!(sendbuf, recvbuf, team::Team; root=0)
UCC.Ibroadcast!(sendbuf, recvbuf, team::Team; root=0, kwargs...) :: Request

Copy sendbuf on rank root to recvbuf on all ranks. sendbuf is only used on root, and may be nothing elsewhere.

The two-buffer form requires immediate, non-persistent posting. For persistent=true or post=false (including triggered posting), use Ibroadcast!(recvbuf, team; ...) and copy into recvbuf on the root before each post, after the previous operation has completed.

Buffers ​

UCC.memory_type Function
julia
UCC.memory_type(buffer) :: LibUCC.ucc_memory_type_t

The UCC memory type of buffer. Host arrays are UCC_MEMORY_TYPE_HOST; GPU array packages add methods through package extensions (e.g. CuArrays when CUDA.jl is loaded). Wrappers such as SubArray defer to their parent.

source
UCC.synchronize_buffer Function
julia
UCC.synchronize_buffer(buffer)

Called on every buffer before a collective is posted. UCC collectives are ordered on the host, so device buffers must have finished any pending writes; the CUDA extension synchronizes the task-local stream here.
