UCC.Library Type
julia
UCC.Library(; thread_mode, coll_types, reduction_types, sync_type,
            config::LibraryConfig) :: Library

Initialize a UCC library instance. Every keyword is optional and only passed to UCC when given:

  • thread_mode: :single, :funneled or :multiple (or the corresponding UCC_THREAD_* value)

  • coll_types: bitmask of UCC_COLL_TYPE_* the application will use

  • reduction_types: bitmask of 1 << UCC_OP_* the application will use

  • sync_type: UCC_NO_SYNC_COLLECTIVES or UCC_SYNC_COLLECTIVES

External links

  • ucc_init, ucc_lib_get_attr, ucc_finalize

UCC.Context Type
julia
UCC.Context([oob::AbstractOOB]; lib, type, sync_type, id,
            config::ContextConfig) :: Context

Create a UCC context. With an oob, the context is wired up with all OOB participants (this blocks until every rank has called Context); a Team can then be created over the same ranks with Team(ctx). Without lib, a default Library is created and destroyed together with the context.

Optional keywords (only passed to UCC when given):

  • type: UCC_CONTEXT_EXCLUSIVE or UCC_CONTEXT_SHARED

  • sync_type: UCC_NO_SYNC_COLLECTIVES or UCC_SYNC_COLLECTIVES

  • id: unique context id

External links

  • ucc_context_create, ucc_context_destroy
source

UCC.free_deferred Function
julia
UCC.free_deferred()

Release the UCC resources of objects that were garbage collected without an explicit UCC.destroy. Finalizers never call into UCC themselves (they may run on any thread, concurrently with UCC calls elsewhere), so call this from the task that drives UCC, while no other thread is using UCC.

Dropped collectives that are still in flight stay deferred until they complete.
