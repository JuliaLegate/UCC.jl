Teams ​

UCC.Team Type
julia
UCC.Team(ctx::Context, [oob::AbstractOOB=ctx.oob];
         ordering, outstanding_colls, sync_type, id) :: Team

Create a team: the UCC analogue of a communicator. All ranks of oob must call Team collectively; the calling process becomes rank oob_rank(oob). Pass a different oob (over a subset of the context's ranks) to create a sub-team.

Optional keywords (only passed to UCC when given):

  • ordering: a UCC_COLLECTIVE_* value of LibUCC.ucc_post_ordering_t

  • outstanding_colls: max number of outstanding collectives

  • sync_type: UCC_NO_SYNC_COLLECTIVES or UCC_SYNC_COLLECTIVES

  • id: unique team id

Teams are not freed by the garbage collector because destruction is a collective operation: call UCC.destroy on all ranks when done.

Examples

julia
ctx  = UCC.Context(UCC.MPIOOB(MPI.COMM_WORLD))   # requires `using MPI`
team = UCC.Team(ctx)
UCC.Allreduce!(x, +, team)
