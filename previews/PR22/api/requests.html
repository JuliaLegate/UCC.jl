Requests ​

UCC.Request Type
julia
UCC.Request

A collective operation returned by the nonblocking collectives (UCC.Iallreduce!, …). Complete it with wait(req) (which returns the receive buffer) or poll it with UCC.test.

Persistent requests (created with persistent=true) can be re-posted with UCC.post! after completing, and must be released with UCC.free.

A dropped request keeps its buffers alive until UCC.free_deferred releases it after completion.

UCC.test Function
julia
UCC.test(req::Request) :: Bool

Progress the team's context once and return whether req has completed. A completed non-persistent request is freed. Throws a UCCError if the collective failed.

Base.wait Method
julia
wait(req::Request)

Block (yielding to other tasks) until req completes, and return its receive buffer (or nothing for barrier-like collectives).
