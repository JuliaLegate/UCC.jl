Execution Engines ​

UCC.ExecutionEngine Type
julia
UCC.ExecutionEngine(team::Team, ee_type, ee_context::Ptr, [ee_context_size]) :: ExecutionEngine

Create a UCC execution engine (e.g. a CUDA stream) on team. With CUDA.jl loaded, use UCC.ExecutionEngine(team, stream::CuStream).

Collectives initialized with post=false can then be posted in stream order with UCC.triggered_post!.

UCC.triggered_post! Function
julia
UCC.triggered_post!(ee::ExecutionEngine, req::Request;
                    ev_type=UCC_EVENT_COMPUTE_COMPLETE) :: Request

Post req (initialized with post=false) so that it starts once the work already enqueued on ee has completed. Complete it with wait(req) as usual.
